# Changelog

Changes a player or GM would notice, newest first. Versions before the first public release were private test builds and are not listed.

## 0.9.0

First public release. The 0.9 releases are the run-up to 1.0.0: the module is complete, and they are there to confirm that installing and updating work for everyone.

### For players

- A guided workshop for building a character from level 1 to 20: ancestry, heritage, background, class, attributes, skills, feats, class path and spells, starting equipment, and each later level's choices.
- The game system's own rule choices are asked on Review, before the character is created.
- Plans are saved on your Foundry account, and can be exported as a file or shared with someone online.
- Sandbox characters, when the GM allows them.
- Promotion requests, and applying each approved level to your character, tested on a copy first.
- Importing a character already in play, with a check against the rules; the character home shows it section by section.
- Retraining, and rebuilding from level 1.

### For GMs

- Books, rarities, trusted compendiums, starting level, starting equipment and kits, alternate ancestry boosts.
- A request queue with per-item Allow, approve, and send back with a note; opening a player's plan and sending suggestions.
- Corrections to a character's attributes, spells, and items, each tested on a copy before the character changes.
- Cited rules for what the installed data does not say, each with a switch, and house rules for extra spell slots.
- A compatibility notice and check when the game system is newer than the verified version.
- Player and GM guides inside the module.

### Upgrading from a private test build

- The module's id changed from `character-builder-lab` to `path-keeper`. Install Path Keeper, disable the old module in Manage Modules, enable the new one, and reload: Path Keeper copies the world's settings, request queue, approved plans, and every player's plans across by itself, and tells the GM when it has. Nothing under the old id is removed; uninstall the old module afterwards.

### Supported

- Foundry Virtual Tabletop 14.
- Pathfinder Second Edition system 8 (verified with 8.7.0) and Starfinder Second Edition system 1 (verified with 1.7.0), including Paizo's Anachronism modules.
