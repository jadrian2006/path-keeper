## What Path Keeper contains

Path Keeper reads the game system installed in a Foundry world (the PF2e or SF2e system) at runtime. It does not ship that system's compendium content: names, descriptions, spells, feats, and icons stay in the system and are shown from it.

Path Keeper does contain a small amount of Licensed Material, all of it game mechanics:

- the rules adjustments in `src/module-rules.js`, each naming the product and page it comes from;
- short fragments of rules wording that its readers look for in the installed system's descriptions (for example, how many spells a class adds to its repertoire at each level).

Its code, rules adjustments, and text contain no Reserved Material: no trademarks used as game content, no proper nouns (characters, deities, locations, organizations, and terms derived from them), no artwork, and no trade dress.

The in-game guides include screenshots of Path Keeper's own interface. Every image the game system supplies is replaced in them (portraits, icons, and logos by a plain placeholder, sheet backgrounds by a flat colour), so they contain no artwork. The names visible in them, such as book and option titles, are the installed system's data as the module displays it; Paizo's trademarks among them are used under Paizo's Community Use Policy, as the guides' notice states, not under this license.
